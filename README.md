# Plugins pessoais

Coleção de plugins pessoais para o Codex. Cada plugin tem sua própria pasta, com manifesto, skills e documentação de uso.

## Plugins

| Plugin | Descrição |
| --- | --- |
| [QA Assistant](qa-assistant/README.md) | Apoia a revisão de código e os testes manuais em equipes sem QA dedicado. |

## Estrutura

Cada diretório de plugin contém um manifesto em `.codex-plugin/plugin.json` e suas skills em `skills/`. Consulte o README de cada plugin para conhecer suas funcionalidades e orientações de uso. A disponibilidade e o método de instalação dependem do ambiente Codex utilizado.
